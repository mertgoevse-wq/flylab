# FlyLab

Scientific digital Drosophila simulation platform.

FlyLab is designed as an Android-first interactive research sandbox for
simulating Drosophila anatomy, nervous system, connectome-derived neural
dynamics, behavior, learning, genetics, physiology, pharmacology,
reproduction and multi-agent interaction.

The system must explicitly distinguish:

- experimentally measured data
- published connectome/anatomical data
- computationally derived data
- modeled behavior
- hypotheses/speculative mechanisms

Initial scientific reference:
FlyWire whole-brain connectome of adult female Drosophila melanogaster.

The long-term goal is an interactive digital organism whose internal state,
brain activity and behavior can be observed in real time.
